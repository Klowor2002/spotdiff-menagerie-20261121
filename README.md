**The Clockwork Menagerie** — an original spot-the-difference game for make.fun's "Make the best spot the difference game" bounty. Four hand-painted canvas rooms (The Brass Workshop, The Aviary Dome, The Midnight Aquarium, The Grand Menagerie) hide 36 differences between them, every one drawn in code: gears that lose teeth, owls whose eyes change colour, a treasure chest that stands open. Find them against the clock: quick finds build a combo worth up to ×5, a wrong click costs five seconds, and three hints per room breathe a ring around one secret. Plays offline in a desktop browser from static files, mouse and keyboard, with synthesized WebAudio sound and no network request.

## Run it

```sh
node serve.ts          # then open http://localhost:8371/game/
# or serve the game/ folder with any static file server
node main.ts /output   # build the platform hand-in (game, screenshots, dossier.json)
```
